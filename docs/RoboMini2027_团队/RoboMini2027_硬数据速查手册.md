## 1. 机器人制作规范（全队必读）⭐

> 机器人需符合制作规范的要求才能通过赛前检录。

### 1.1 能源

| 项目 | 规定 |
|---|---|
| 禁止 | 燃油驱动的发动机、爆炸物、危险化学材料 |
| 允许形式 | **仅电源和气源两种** |
| 电源 | 需使用**正规厂家**生产的锂电池或干电池；**最大电压值 16.8 V** 📌 |
| 气源 | 见 1.2 |

### 1.2 气源（若使用压缩气体作为动力系统）

| 项目 | 规定 |
|---|---|
| 气瓶存储气压 | **≤ 20 MPa** |
| 气瓶标称耐压 | **≥ 30 MPa** |
| 恒压阀 | 气瓶出口**直接安装双表恒压阀** |
| 工作气压 | **≤ 0.8 MPa** |
| 工作气体 | 不可燃烧、无毒、无污染（如空气、氮气、二氧化碳） |
| 资质 | 需有合格证书或铭牌钢印（检录时方便查看）；需原产地国家官方认证机构颁发认证证书 |
| 维护 | 寿命期内按说明书/铭牌规定期限返厂维护，并提供维护证明 |
| 防护 | 气瓶及输气管需施以保护，防侧翻/碰撞/旋转/运动部件故障损坏；**瓶口不得外露** |
| 安装 | 任意角度翻滚时瓶与管都不得接触地面；**瓶口必须水平或朝上**；瓶体至少 2 个固定点（间距 > 1/5 瓶身长度）或有 > 1/5 瓶身长度的固定面 |
| 隔离 | 气瓶与任何热源之间需有隔离层 |
| 管路 | 输气管和配件需适用于系统最大工作压力；**建议低压气路安装安全泄压阀** |

### 1.3 无线电

- 机器人**仅允许采用无线方式控制**
- 允许：WiFi、蓝牙、2.4GHz、5GHz 等
- 无线遥控**功率不能太大**，不允许通过大功率无线电干扰裁判系统或对方机器人

### 1.4 外观设计

| 项目 | 规定 |
|---|---|
| 线路 | 整齐、**不裸露**；无法避免的外露线材需用**拖链、理线器**等材料保护 |
| 线束 | **所有线束应固定**，避免线束缠入旋转部分 |
| 材料 | 外观中不得出现明显影响美观的材料 |
| 结构 | 避免尖锐结构造成场地破坏和人员伤害 |

> 📌 1.4 与硬件加分项「自制主控后整车布线的整洁程度和电气连接可靠性 +10」**直接挂钩**——布线规范既是检录门槛，也是得分项。

### 1.5 制作参数（硬约束）⭐📌

| 项目 | 数值 |
|---|---|
| 机器人最大初始尺寸（L×W×H，**不含手动控制器**） | **350 × 350 × 400 mm** |
| 检录要求 | 赛前检录时尺寸**必须小于**最大初始尺寸 |
| **伸展** | **比赛开始后，机器人可以任意伸展，最大伸展尺寸不进行限制** ⭐📌 |
| 重量 | **≤ 15 kg** |
| 操作方式 | 需满足规范 |

> 💡 **这是个关键设计窗口**：检录时收进 350×350×400，开赛后不受限。
> ⇒ 折叠／升降／伸缩机构在规则上是**被明确允许**的，可以作为取顶层能量单元（300 mm）的主要思路。

### 1.6 发射装置规范 ⭐📌

| 类别 | 规定 |
|---|---|
| **发射物** | 仅允许组委会指定规格的乒乓球（**GB/T 20045**）；调试可用自购同规格球，**比赛只能用赛方提供的** |
| **发射方式** | **禁止气动、火药方式发射** |
| **供电** | 发射装置电压 **≤ 16.8 V**；须有**可切断发射动力的总开关或急停** |
| **尺寸** | 发射装置尺寸（L×W×H）**< 300 × 300 × 300 mm** |
| **射界** | 不得向人员、观众区、裁判区或场外发射 |
| **失控保护** | **失控 0.5 s 内断电**；急停或总开关立即断电 |
| **自动瞄准** | 允许使用自动瞄准或视觉识别，**但必须保留人工急停** |
| **堵转保护** | 电机驱动器应有堵转保护；**供弹卡滞时，电机堵转时间不得超过 2 s，应自动断电**，不得以堵转方式持续供弹 |
| **结构** | 需保证发射过程平稳，不得大幅度晃动 |
| **故障处理** | 卡球或故障：先举手示意裁判，**断电或急停后**处理；**不得在通电状态下将手伸入发射口** |

> 📌 **对电控的直接要求**（检录必查项）：
> ① **0.5 s 失控断电** → 需要做通信看门狗 + 断电执行电路
> ② **2 s 堵转断电** → 需要做电机电流检测 + 定时切断
> 以上两项同时也对应硬件加分项「各种保护电路 +10」。

## 4. 比赛机制

### 4.1 得分路线与记账

| 路线 | 兑换及硬件收益 | 得分来源 | 公式 |
|---|---|---|---|
| **分数优先** | 直接计分，**不获得允许发弹量** | 有效兑换分 + 有效硬件加分 − 扣分 | **S = E + H − P** |
| **弹丸优先** | 按 10 分对应 1 颗乒乓球额度转换，**不重复计分** | 有效命中得分 − 扣分 | **S = T − P** |

- 每队须在**每场比赛开始前**申报路线，**本场不得变更**，各场分别申报
- 扣分计入比赛成绩，**不自动扣减弹丸额度**
- 赛后先比较扣分后总分，总分高者获胜；总分相同按 5.8 比较；**红牌判负优先于分数比较**

### 4.2 兑换价值与同时兑换

| 有效兑换组合 | 基础价值合计 | 倍率 | 分数优先所得 | 弹丸优先所得 |
|---|---|---|---|---|
| 1 个方块 | 20 分 | ×1 | 20 分 | 2 颗 |
| 2 个方块同时兑换 | 40 分 | **×2** | 80 分 | 8 颗 |
| 1 个能量单元 | 50 分 | ×1 | 50 分 | 5 颗 |
| **2 个能量单元同时兑换** | 100 分 | **×2** | **200 分** | **20 颗** |
| 1 个方块 + 1 个能量单元同时兑换 | 70 分 | **×2** | 140 分 | 14 颗 |

**同时兑换成立条件** ⭐（三条件全中）

1. 两个资源物品分别经**两个不同孔**投入
2. 检测**时间差 ≤ 1 秒**
3. 物品可为同类，也可为 1 方块 + 1 能量单元

**关键细节** ⭐

- **时间差由激光检测模块记录**
- **一个能量单元可独立兑换，无须等待配对**
- 不满足时（同一孔投入，或不同孔但时间差 > 1 秒）→ **按各物品基础价值分别结算**

### 4.3 弹丸额度与实物管理 ⭐（本轮新增，电控必读）

**流转流程**

```
硬件检测确认加分 → 开赛领取相应数量实物弹丸
                          ↓
比赛中有效兑换 → 裁判确认新增额度 → 向本方补弹人员发放 → 补弹人员装填发射架
```

**记账规则**

| 项目 | 规定 |
|---|---|
| 换算 | 每 10 分兑换价值 = 1 颗弹丸；弹丸额度均为**整数** |
| 裁判记账 | 分别记录 **累计获准额度 A**、**累计已发放数量 F**、**累计已发射数量 N** |
| 约束 1 | 累计已发放数量 **F ≤ 累计获准额度 A** |
| 约束 2 | **剩余允许发弹量 = A − N** |
| 约束 3 | 实际装填和发射**还须以已领取且尚未使用的实物弹丸为限** |
| 约束 4 | 获准额度与实物发放**分别记账**，同一笔收益不得重复记录 |

> 📌 **对电控的直接含义**：发射架需要一套**弹丸计数与发射授权的闭环管理**——
> 多发一颗 −20 分（见 6.2），这比一次自主大能量机关命中的 2/3 还贵。

### 4.4 打靶阶段推进

| 规则 | 内容 |
|---|---|
| 进度 | 双方打靶进度**独立** |
| 每阶段／轮 | 须依次有效命中 **5 个不同靶**，五靶全部由待激活转为已激活才算完成 |
| 顺序 | 固定靶 → 随机固定靶 → 之后可选小／大能量机关（每轮完成后重新选择，**可重复选同一模式**） |
| 次数限制 | **固定靶和随机固定靶每场各只完成一次** |
| 重复命中 | 同一靶在同一轮只能有效激活一次，**重复命中已激活靶不计分、不推进阶段** |
| 不要求 | **不要求**先完成小能量机关才能挑战大能量机关 |
| 结束时 | 未完成一轮的有效命中**仍逐次计分** |

### 4.5 四种打靶模式与命中分值

| 模式 | 旋转方式 | 灯板切换 | 人工每次命中 | 自主每次命中 |
|---|---|---|---|---|
| 固定靶 | 不旋转 | 当前待激活靶**持续显示**待激活灯效；命中后转已激活，再从未激活靶中随机选择 | 15 分 | 30 分 |
| 随机固定靶 | 不旋转 | 待激活靶显示 **3 秒**后切换；命中后下一目标仅从未激活靶中选择 | 20 分 | 40 分 |
| 小能量机关 | 匀速 **π/3 rad/s** | 显示 3 秒后切换 | 25 分 | 50 分 |
| 大能量机关 | **周期变速** | 显示 3 秒后切换 | 30 分 | 60 分 |

**目标切换细节** ⭐

- 随机固定靶、小／大能量机关中，当前待激活靶显示 **3 秒**仍未被有效命中时，切换待激活目标
- 切换后：**只有当前选中的待激活靶 4 条全亮**，其他未激活靶**全部熄灭**；已激活靶保持两侧亮，**已取得的激活进度不变**
- **固定靶未命中时持续保持当前待激活目标**（不切换）

### 4.6 大能量机关转速函数

$$\text{spd}(t) = a \sin(\omega t) + b,\quad b = 2.090 - a$$

| 参数 | 取值 |
|---|---|
| $a$ | **0.780 ～ 1.045** |
| $\omega$ | **1.884 ～ 2.000** |
| 单位 | spd：rad/s；t：s |
| 时间误差 | 实际转速相对目标函数的时间误差应在 **500 ms** 以内 |

### 4.7 灯效与有效命中

**三种灯效状态** ⭐（本轮细化）

| 状态 | 灯条表现 | 含义 |
|---|---|---|
| 未激活（未选中） | 上、下、左、右 **4 条全灭** | 当前不开放命中 |
| **待激活** | **4 条全亮** | **当前唯一有效目标** |
| 已激活 | 仅**左、右 2 条**点亮，上、下熄灭 | 本阶段／本轮内重复命中无效 |

- 靶面由**两根支臂**支撑，十字灯条中**一条沿径向指向能量机关中心**
- 已激活时点亮的是**径向两侧的两条灯条**，其画面朝向随靶位和机关转动而变化
- 每方每次**仅有 1 个靶**显示待激活灯效

**有效命中须同时满足 4 条**

1. 本次发射**合法且有额度** ⭐
2. 使用规定乒乓球
3. **直接命中**本方当前显示待激活灯效的**唯一有效靶区**
4. 由当值裁判确认

**以下情况不计本方得分、不增加激活数量**

反弹命中 · 击中已激活靶 · 击中非当前待激活靶 · 击中边框或支撑结构 · 击中对方目标

### 4.9 人工与自主控制

| 项目 | 规定 |
|---|---|
| **人工模式** | 操作手通过**遥控器或电脑键鼠**控制发射架瞄准和发射 |
| **自主模式** | 程序完成目标识别、瞄准和发射；运行期间**不得由人持续操控**遥控器或电脑 |
| 自主指令输入 | 仅在**切换能量机关阶段**或**获得新增允许发弹量**时，允许进行**不超过 5 秒**的指令输入 |
| 算力设备 | 发射区**可使用电脑**作为算力设备 |
| 故障切换 | 先停止发射并申请切换 → 裁判确认在途弹丸已完成判定 → 记录切换生效时刻 → 允许人工接管 |
| 切换后果 | **本场比赛不得恢复自主模式**；赛前申报人工模式的队伍**也不得**切换为自主模式 |

> ⭐ **重要澄清**：手册明确「本手册所称人工模式、自主模式**均指发射架的控制模式，与拾取车是否自主运行无关**」。
> ⇒ **拾取车可以自主运行，这不违反任何规则，也不需要在赛前申报。**

## 6. 比赛流程

### 6.1 赛前检录及准备

1. 参赛机器人按**制作规范**完成检录
2. 硬件加分**另经文件审核和功能检测**，结果登记在当场记录表中
3. 通过检录后进入候场区，由工作人员引导入场
4. 每场赛前申报得分路线；弹丸优先队伍同时申报人工或自主模式
5. 裁判记录本场硬件收益、初始弹丸额度及已发放球数，核查场上资源总量和双方机关初始状态
6. **比赛开始前 1 分钟**：拾取车放入本方启动区；申报上场的发射架安装于本方发射区
7. 仅在裁判宣布比赛开始后，方可执行比赛动作
8. 准备阶段总时长及检录、候场安排按赛事通知执行 ❓

### 6.2 七分钟比赛阶段

- 裁判发出开始信号并开始计时
- 双方执行拾取、兑换及打靶任务，裁判实时记录兑换、发球、命中、模式切换和判罚
- 比赛阶段为 **7 分钟**
- **队伍自身故障、维修和救车不停止比赛计时**

### 6.3 故障检修

| 项目 | 规定 |
|---|---|
| 位置 | 拾取车发生故障时可返回**本方启动区**检修 |
| 无法移动 | 经裁判确认，可由**最多 2 名**队员搬回 |
| 工具 | **可使用电脑和调试工具** ⭐ |
| 计时 | 检修时长**计入比赛时间** |
| 扣分 | **非翻车类故障检修不扣分** |

### 6.4 翻车救援

| 项目 | 规定 |
|---|---|
| 触发 | 机器人因翻车或倾倒丧失运动能力 |
| 流程 | 队伍申请救车 → 经裁判允许 → 最多 2 名队员进场 → 按 4.11 处理携带资源 → 搬回本方启动区 |
| 小组赛 | 救车**不扣分** |
| 淘汰赛 | 每次实施人工救车 **扣 5 分**，次数不限；之后是否检修、是否超过 30 秒，**均不取消本次扣分** |

### 6.5 比赛结束及成绩确认

1. 结束信号发出后，队伍立即停止所有比赛操作
2. 裁判核对：资源兑换记录、发球与发射记录、各难度及控制模式下的有效命中、硬件收益、救车和判罚
3. 计算总分并按 4.10 判定胜负
4. 队伍按工作人员指引取回设备

**8.3 实物与记录不一致**

- 赛中发球数量、兑换物品或命中记录发生冲突时，应立即核对当次事件及原始记录，**保留更正前后内容**
- 裁判误发球须先停止额外使用并核账，**不自动视为队伍故意作弊**；已发生后果由主裁按事实处理

### 7.6 成绩复核与申诉

- 有关规则疑问和比赛争议，**统一向主裁提出**
- 成绩确认环节可核对 6 项：**兑换分类、同时兑换、硬件收益、弹丸账目、有效命中、扣分记录**
- 提出复核或申诉时，应**说明相关条款及事实依据**
