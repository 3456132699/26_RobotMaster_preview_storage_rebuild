# 风险登记表

> **活文件**：每周更新一次。**不写"暂无风险"**——写"暂无风险"的队伍，风险都在赛场上出现。
> 配套：`../RoboMini2027_开发流程与各组产出物.md`（各阶段风险来源）

---

## 使用规则

1. **只写会影响成绩或能不能上场的事**，不写"可能会累"
2. **必须有「早期征兆」**——没有征兆的风险，等于没法预警
3. **必须有负责人**——集体负责 = 没人负责
4. 每周复查一次：升级 / 降级 / 关闭，都要写日期
5. 下面已经预填了 14 条**已知风险**（从规则和三份文件里推出来的），你们可以在此基础上增删

---

## 等级怎么定

| | 影响小 | 影响中 | 影响大 |
|---|:--:|:--:|:--:|
| **很可能** | 🟡 黄 | 🟠 橙 | 🔴 红 |
| **可能** | 🟡 黄 | 🟡 黄 | 🟠 橙 |
| **不太可能** | 🟢 绿 | 🟡 黄 | 🟠 橙 |

> **红**：本周就要动手。**橙**：两周内要有对策。**黄**：盯着。**绿**：记着就行。
