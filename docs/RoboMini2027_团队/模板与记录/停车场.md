# 停车场

> **活文件**：会上随时加，会后 48 小时内清。清完不删记录，改成 `已清` 留着。
> 用途：把「不知道」从会议流里摘出去，但保证它不会消失。

---

## 使用规则

1. **任何人、任何时刻**可以说「这条进停车场」，不许被反驳、不许被追问
2. 编号连续，**不重用**（P1 用过就是 P1，删了也不再给别的问题）
3. **每条必须有负责人 + 清空期限**——没有负责人的停车场，等于垃圾桶
4. 会后 **48 小时内**清空：查到答案发群里，把答案写进本表
5. **不许挡住拍板**——如果它真的挡住了某个决策，说明它是决策级问题，当场处理
6. 超时未清的，**下次会议开头先过**

---

## 状态说明

| 状态 | 含义 |
|---|---|
| `悬挂` | 已记录，答案还没查到 |
| `已清` | 答案已在「答案要点」列 |
| `转决策` | 发现它是决策级问题，已转进决策日志 |
| `作废` | 前提变了，问题不存在了（写明为什么） |

## 常见问题分类（帮你判断该挂还是该问）

| 这类问题 | 处理方式 |
|---|---|
| 规则条款具体数值记不清 | **挂起**，报保守值继续讨论 |
| 官方还没公布的参数 | **挂起**，按包络估算，标注"待组委会" |
| 某个技术原理不懂 | 看它影不影响当前拍板：影响→当场问；不影响→**挂起**，会后学 |
| 两个方案都行、各有优劣 | **不是停车场问题**，是决策问题——投票，进决策日志 |
| 需要实测才知道 | **挂起**，但要写清"怎么测、谁测、什么时候测" |
