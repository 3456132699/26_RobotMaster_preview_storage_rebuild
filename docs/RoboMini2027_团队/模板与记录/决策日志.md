## 使用规则

1. **会上填，不带走**——留到会后靠回忆填的日志，错误率极高
2. **每条必须有「谁拍板 + 为什么」**——只有结论没有理由的，三周后一定被推翻
3. **状态只有四种**：

| 状态 | 含义 | 后续动作 |
|---|---|---|
| `已定` | 结论明确，无人反对 | 冻结后改动走「变更记录」 |
| `待验证` | 带条件通过，依赖某个未确认的信息 | 条件确认后改 `已定`，并补变更记录 |
| `挂起` | 今天定不了，已进停车场 | 停车场清空后回来补 |
| `未定` | 还没讨论到 | — |

4. **变更记录格式**：`原方案 → 新方案 ｜ 原因 ｜ 影响到谁 ｜ 日期`
5. **冻结后任何改动都要在群里说一句**——没有记录的口头改动，一律视为没改
