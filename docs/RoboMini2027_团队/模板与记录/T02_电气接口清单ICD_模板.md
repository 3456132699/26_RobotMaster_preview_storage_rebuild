## 一张清单回答四件事

1. 谁跟谁**通信**？什么协议？速率多少？
2. 谁给谁**供电**？几伏几安？峰值多少？
3. **地怎么共**？（共地是所有疑难杂症的源头）
4. **机械接口**：板子多大、几个孔、孔距多少、线从哪出？

## 表 3 · 电源预算（最容易被漏的一张）

| 电源轨 | 供电对象 | **峰值电流** | **平均电流** | 器件 | 选型结论 |
|---|---|:--:|:--:|---|---|
| VBAT | 电池输入 | A | A | 4S（≤16.8 V） | |
| 电机轨 | 底盘 ×?、升降 | A | A | 电池直驱 + PWM | |
| 6 V | 舵机 ×? | A | A | Buck | |
| 5 V | 相机 / 接收机 / 传感器 | A | A | Buck | |
| 3.3 V | MCU / 逻辑 | A | A | LDO（从 5 V 取） | |

**三条铁律**

- 峰值与平均**分开算**（电机启动是额定的 3～8 倍）
- **电机那一路必须独立**，不能和 MCU 共用 → 根治「电机一转就复位」
- 器件按**峰值的 1.3 倍**选；电池容量按平均算、倍率按峰值算
