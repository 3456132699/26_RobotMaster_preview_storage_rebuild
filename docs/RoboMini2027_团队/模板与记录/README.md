# 模板与记录 · 使用说明

> 这个文件夹装两类东西，**名字一样，用法不同**——别混。
>
> | 类型 | 特征 | 怎么对待 |
> |---|---|---|
> | **模板** | 文件名带 `T__` 前缀，比如 `T01_决策日志_模板.md` | **只读**，复制一份出来用，不往里填 |
> | **记录** | 不带前缀，比如 `决策日志.md` | **活文件**，一直往里加，不删历史 |

## 2. 命名规则（很重要，防丢）

```
模板：T__名称_模板.md           例：T02_电气接口清单ICD_模板.md
活文件：名称.md                 例：决策日志.md
一次性记录：名称_YYYY-MM-DD.md   例：周报_2026-11-08_电硬.md
版本化文件：名称_v1.0.md         例：电气接口清单ICD_v1.0.md
```

**四条硬规则**

1. **日期写 `YYYY-MM-DD`**，不要写 `11.8` 或 `周日`——排序会乱
2. **不要在文件名里写"最终版""最新"**——用 `v1.0 / v1.1 / v2.0`，`v` 后面第一位是冻结次数
3. **冻结后的文件不改名、不覆盖**，新建 `v2.0`
4. **移动或改名文件，必须在群里说一句**（这是全队的约定，也包括我）

> 周报先直接放在本文件夹，命名 `周报_YYYY-MM-DD_组名.md`；攒到 10 份以上再建 `周报/` 子文件夹。

## 3. 三个"活文件"怎么配合用

```
会议中 ──→ 停车场.md        记下所有"不知道"
         └→ 决策日志.md      记下所有"定了什么"
                │
                ├→ 带条件的假设 ──→ 停车场清空后回填「变更记录」
                │
                └→ 改动影响范围 ──→ 风险登记表.md
```

- **决策日志**回答「我们定过什么、为什么」
- **停车场**回答「我们还欠什么答案」
- **风险登记表**回答「哪里可能会崩、谁在盯」

三份都空着，说明要么没开会，要么没留痕。

## 4. 权限与备份

- 这个文件夹**需要上传仓库**（团队共享）
- **快照靠 git，不靠复制**：每周日提交一次，commit message 写「周报 W?? + 决策日志更新」——改坏了能退回去
- 涉及个人的东西（学习笔记、个人清单）放 `RoboMini2027_电硬/`，**不要混进来**

---

## 5. 什么时候该再分子文件夹

现在这样平铺就够了。出现下面任一情况，再考虑加子文件夹（**加之前先说一声**）：

- 某个文件超过 300 行，翻起来费劲
- 同一类记录超过 10 份（比如周报攒了十几份 → 建 `周报/`）
- 有两个人同时改同一个文件，互相覆盖
