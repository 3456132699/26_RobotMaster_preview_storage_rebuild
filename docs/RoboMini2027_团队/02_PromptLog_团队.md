2. **答辩素材**：赛事结束的汇报答辩，展示真实的协作过程和决策思路
3. **纪念**：我的第一个大学项目

## 1. 怎么查（给白星，也给长庚）

**先查索引表（§2），再跳到条目。** 每条开头都有一行「关键词」，也可以全文搜索。

## 第 1 条 · 2026-11-02｜从一本规则 PDF 到三个问题　`#TL01`

关键词：`#起步` `#规则解读` `#路线对比` `#电硬视角`

项目第一天。我拿到规则 PDF，提了三个要求。

| 我输入的片段 | 长庚把它变成了什么 |
| --- | --- |
| 「帮我：1.汇总关键参数数据生成文件 2.比较两条路线难度 3.结合电硬方向分析难度」 | 不是"总结一份 PDF"，而是**给电控硬件这个岗位的决策视角**：参数表、两条路线的量化对比（分数优先上限 ≈900 且同分必输 / 弹丸优先上限 1400+）、以及"硬件加分 100 分是唯一确定性收益"这个关键判断 |
| 我交代了背景：大一队伍、各管一摊、我来电硬 | 他把"你是谁"放进了所有分析的口径里——后续每一份文件都是按"6 个大一新生"的现实约束做的，没有套用成熟战队的标准 |

**产出**：`RoboMini2027_规则关键参数与路线分析.md`、`RoboMini2027_路线对比看板.html`

**值得留的反省**：第一轮的 PDF 只有 43 页"解读"，尺寸/重量/电压这些**图片里的数据没提取到**。长庚当时标了出来而不是编数字——后来这批数据在《制作规范》里补齐。这是"**绝不使用模糊结论**"这条规矩的最早实例。

## 3. 维护规则

- **谁加**：默认由长庚在每次"值得记的对话"后主动补（判断标准见技能的五类：功能怎么长出来的 / 立规矩 / 互相拦 / 价值判断 / 踩坑修复）。我随时可以点名「这段值得记」
- **什么时候加**：定完一条重要决策、改完一份重要文件、或我发现"这段对话以后会有用"的当下。**不当场记，三天后就只剩大意了**
- **格式**：编号连着往下排，不重排旧条目；写错事实就新加一条更正，不改历史
- **红线**（沿用）：不编造原话（记不清就标「大意」）；不美化弯路；负面情绪不进材料；日期不确定写区间
